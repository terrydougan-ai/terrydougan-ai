## What's in this profile

The repositories pinned below are personal projects I've built to explore questions I've been thinking about in my work while at the same time getting back to my hands-on coding roots and trying out some of the powerful new AI tools. These apps are not yet products — they're sketches in code of the modeling decisions I'd want any planning or operations tool to get right. Each one is its own thing:

* [okr-planning-app](https://github.com/terrydougan-ai/okr-planning-app) — an honest take on OKR tooling that connects strategy, work, and outcomes end-to-end. It separates delivery from impact, exec-facing signal from team-facing status, and leading from lagging indicators. Claude is layered in for specific moments — proposing KRs, summarizing exec views, reviewing check-ins against a rubric, and drafting check-ins from ambient signals (simulated Jira, Slack, and calendar activity) so a PM edits a substantive first draft rather than composing from a blank field. Built to surface the cross-functional coordination work that most tools flatten — where one team's initiative is moving another team's KR.
  
* [job-search-command-center](https://github.com/terrydougan-ai/job-search-command-center) — an AI-driven command center for a senior job search. It scores each role against your resume and stated preferences, separates genuine fit from surface-level keyword matches, enriches opportunities with live company-reputation signals, and manages the whole pipeline — turning a noisy, manual hunt into a ranked, data-driven one.
